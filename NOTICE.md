# Notice

This branch preserves the native 32-bit Vocalizer Automotive 2.1.6 driver
with the NVDA 2025 compatibility modification attributed in the source.
It is maintained independently and is not an official Tiflotecnia release.

Driver source is covered by the included GNU GPL text. Automotive engine
components are separate runtime files. The build restores the exact four
runtime files present in this fork's published NVDA 2025 package from Git
objects already in a full repository clone. It does not fetch a user license.
Separate voice add-ons and a valid user license remain required.
